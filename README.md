# terraform_cicd
Creating aws resources using terraform

step 1:
Install Java version 17 or 21.

step 2:
Install Jenkins in local.

step 3:
Create AWS user with access key and secret key.

step 4:
Sign in to git repo.

step 5:
Install Git plugin.

step 6:
Add git creds, access key and secret key in the jenkins creds.

step 7:
Create a pipeline in Jenkins by giving source as git.

step 8:
Install terrform in local and give the local path in jenkins file.

step 9:
Run the pipeline.
